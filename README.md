# Nyx Research Notebook

The installable build of Nyx: a local-first notebook for structured research, analysis and reporting. This repository holds only the app. No notes, cases or reports are stored here; they live in the browser on each device.

Served from GitHub Pages at `https://averyjordanr.github.io/nyx/`.

## Install

- **Galaxy Z Fold**: open the address in Chrome, then menu > Add to Home screen (or Install app).
- **iPad / iPhone**: open it in Safari, then Share > Add to Home Screen.

## Updating

Replace `Research_Journal.html` (and any changed files) with the copies from the project's `deploy/` folder and commit. The installed app picks up the new build the next time it opens with a connection.

## Moving work between devices

Each device has its own notebook. Use Backups > Back up now on one device and Restore on the other, or a case bundle from a case's Archive tab.
