Help & Reference

Getting Started

1. Add nodes
Press A or click + Node, then click anywhere on the canvas. Choose an entity type and color first.
2. Connect nodes
Press C or click Connect, then click a source node followed by a target node. An arrow is drawn.
3. Explore & analyze
Right-click any node for analysis options: highlight neighbors, find shortest path, or show centrality.

Modes

🖱 Select (S)
Click to select nodes. Drag to move. Shift+click for multi-select. Right-click for context menu.
➕ Add Node (A)
Click canvas to place a new node. It inherits the currently selected entity type and color.
🔗 Connect (C)
Click source node, then target node. Creates a directional edge with an arrow.
▬ Lasso (L)
Drag a rectangle to select multiple nodes at once. Use with "Create group" in the context menu.
📝 Annotate (T)
Click canvas to place a draggable text annotation. Type notes directly. Drag the box to reposition.

Node Properties

🏷 Label & Description
Click a node to edit its name, description, group, size, type, date, and confidence level.
🔒 Confidence
Confirmed = solid border. Suspected = dashed orange border. Unverified = dotted gray border.
# Degree badge
Each node shows its connection count as a small number badge.

Edge Properties

✏️ Label & Weight
Click an edge to edit its label, weight (controls thickness), line style, and date.
— Line styles
Solid = confirmed. Dashed = suspected. Dotted = unverified. Right-click an edge to delete.

Analysis (Right-Click Menu)

🔍 Highlight neighbors
Dims all unconnected nodes to focus on the selected node's direct connections. Clears after 4 seconds.
📏 Shortest path
After clicking, select a target node. The shortest path highlights in gold with step count. Clears after 5 seconds.
📊 Centrality
Auto-sizes all nodes by degree centrality. Larger nodes = more connections = more important.
📌 Create group
Select multiple nodes (Lasso or Shift+click), then right-click > Create group. Draws a colored boundary with a label.

Navigation

🔎 Zoom
Scroll to pan the canvas; pinch or Ctrl+scroll to zoom. Drag empty canvas (or hold Space) to grab and pull the view.
↩ Undo / Redo
Ctrl/Cmd+Z to undo, Ctrl+Y or Ctrl+Shift+Z to redo (60 levels). Covers adds, deletes, moves, property edits, layouts, imports, and Clear All.
☈ Selection ops
Ctrl+D duplicate, Ctrl+C/V copy & paste. Right-click a multi-selection for align, distribute, and bulk color/type.
📑 Attributes
Add key/value fields to any node in the properties panel. Search matches attributes and descriptions too.
📊 Analytics
Size nodes by degree, betweenness, or closeness centrality. Detect Communities recolors nodes by cluster (Ctrl+Z to revert).
▶ Timeline playback
Press Play in the Timeline bar to animate the network chronologically. Dated nodes and edges appear as time advances.
👤 Photos & shapes
Give nodes a photo or a square/diamond shape from the properties panel. Both carry into the journal, print, and exports.
📍 Views & minimap
Save named camera+filter views for briefings. The minimap (bottom right) shows the whole chart; click it to jump.
🗃 My Charts
Browse, rename, open, and delete all saved chart workspaces. Merge Duplicate Nodes unifies entities that share a name.
📦 Exports
PNG (raster), SVG (vector, print quality), GraphML (opens in Gephi/yEd), and JSON (re-import into the journal).
✋ Pan
Ctrl+drag (or Cmd+drag on Mac) to pan the canvas. Middle mouse button also pans.
⊞ Fit to Screen
Auto-zooms to show all nodes with padding. Found in the Layout section.
↺ Reset Zoom
Returns to the default 1:1 zoom level.

Layouts

Force — Physics simulation, connected nodes pull together.
Hierarchy — Top-down by importance (most connected at top).
Circular — All nodes arranged in a circle.
Grid — Evenly spaced grid arrangement.

Filtering

🔢 Degree filter
Slider hides nodes with fewer than N connections. Reveals the backbone of the network.
📅 Timeline filter
Set From/To dates to show only edges within a date range. Edges without dates always show.
🔍 Search
Type a node name to find and select it instantly.

Import / Export

📊 CSV Import
Paste edge data: From,To,Label,Weight,Style,Date (one per line). Only From and To are required. Auto-creates nodes.
{ } JSON
Export/import full chart state including nodes, edges, groups, and annotations.
🖼 PNG
Export a high-resolution screenshot. Use this to paste into the Research Journal via an Image block.

Tips

• All data auto-saves to localStorage.
• Export JSON regularly as a backup.
• Use the Legend panel to see what colors and icons mean.
• After CSV import, click Force layout to auto-arrange.
• Centrality analysis resizes nodes — use Reset Zoom + Fit to Screen after.
• To use in the Research Journal, export as PNG and add via Image block.
